# AI Workplace Productivity Assistant

**An AI-powered productivity platform for smarter workplace communication, research, and everyday tasks.**

Developed by **Philela Mbombo** as a school project exploring how artificial intelligence can improve workplace productivity.

---

## 📌 Project Overview

The **AI Workplace Productivity Assistant** is a modern, responsive web application designed to help professionals work more efficiently using artificial intelligence.

The application brings essential AI productivity tools into one professional workspace, allowing users to generate professional emails, summarise research material, explore ideas, and receive assistance with workplace-related questions.

The project focuses on usability, productivity, responsible AI adoption, and a clean, professional SaaS-style interface.

### 🎯 Project Objectives

- Improve workplace communication through AI-generated content.
- Reduce the time required to draft professional emails.
- Simplify research through AI-powered summaries and insights.
- Provide an interactive AI assistant for workplace questions.
- Promote responsible and informed use of artificial intelligence.
- Demonstrate how AI can be integrated into a user-friendly web application.

## ✨ Features

### 1. Smart Email Generator

Generate professional emails based on user-provided instructions and context.

**Key capabilities:**
- Generate emails tailored to a specific purpose.
- Support three writing tones:
  - **Formal** — professional business communication.
  - **Friendly** — approachable and conversational communication.
  - **Persuasive** — communication designed to encourage a particular response.
- Generate relevant email subject lines.
- Edit generated email content before using it.
- Copy, regenerate, or clear email drafts.

### 2. AI Research Assistant

Explore topics and understand information more efficiently.

**Key capabilities:**
- Research topics and answer questions.
- Summarise pasted articles and text.
- Identify key findings and important considerations.
- Generate practical insights and recommendations.
- Analyse website content when supported by the configured AI integration.
- Communicate limitations when source material cannot be accessed.
- Present research results in an editable output area.

### 3. AI Workplace Chatbot

Interact with an AI assistant through a conversational interface.

**Key capabilities:**
- Ask workplace-related questions.
- Improve professional writing and communication.
- Brainstorm ideas and explore solutions.
- Summarise supplied information.
- Prepare meeting agendas and workplace messages.
- Receive context-aware answers when supported by the AI integration.

### 4. Modern Dashboard

A professional dashboard provides convenient access to the application's productivity tools.

**Key capabilities:**
- Clean, modern SaaS-inspired interface.
- Sidebar navigation.
- Responsive desktop and mobile layouts.
- Quick access to the main AI tools.
- Clear loading indicators and error feedback.
- Consistent typography, colours, spacing, and interface components.

### 5. Responsible AI

The application promotes responsible use of artificial intelligence.

**Key principles:**
- Encourage verification of important information.
- Warn users against submitting confidential or sensitive information.
- Promote human oversight of AI-generated content.
- Communicate uncertainty and technical limitations.
- Avoid presenting unavailable or unverified information as fact.

> **Important:** The actual availability of these features depends on the implemented application and its AI configuration. Features should be considered complete only after they have been tested successfully.

## 🚀 Getting Started

Follow these instructions to run the project locally, assuming it uses a typical Node.js frontend setup.

### Prerequisites

Before running the application, ensure you have:

- [Node.js](https://nodejs.org/) installed.
- npm or the package manager specified by the project.
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/).
- Access to the configured AI service if live AI features require an API key.

### Step 1: Clone the Repository

Replace `YOUR_USERNAME` and `YOUR_REPOSITORY` with your GitHub username and repository name.

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### Step 2: Open the Project Directory

```bash
cd YOUR_REPOSITORY
```

### Step 3: Install Dependencies

For an npm-based project, run:

```bash
npm install
```

### Step 4: Configure the AI Integration

Check the project's documentation and environment configuration for details about the AI provider and required settings.

If an API key is required, follow the provider's official instructions.

**Security considerations:**
- Never commit private API keys, passwords, or other secrets to GitHub.
- Do not embed a private API key directly in frontend code.
- Use an integration designed for secure browser use, or a secure server-side component if the provider requires one.
- Check the AI provider's usage limits, pricing, and data-handling policies.

If an AI integration has not been configured, the interface may load without being able to generate genuine AI responses.

### Step 5: Start the Development Server

For a typical Vite-based project, run:

```bash
npm run dev
```

Open the local URL displayed in your terminal. A common default is:

```text
http://localhost:5173
```

The exact commands and URL may differ depending on the generated project.

## 📖 How to Use the Application

### Email Generator

1. Open the Email Generator from the sidebar.
2. Enter the purpose of the email and the relevant details.
3. Select Formal, Friendly, or Persuasive.
4. Generate the email.
5. Review, edit, and copy the output.

### Research Assistant

1. Open the Research Assistant.
2. Enter a research topic, question, or article text.
3. Provide a URL if supported by the configured integration.
4. Generate the research summary.
5. Review the findings, insights, and recommendations.
6. Verify important claims against reliable sources.

### AI Workplace Chatbot

1. Open AI Workplace Chat.
2. Enter a workplace-related question or task.
3. Submit the prompt.
4. Review the AI response.
5. Ask follow-up questions when conversational context is supported.

Always review AI-generated information before using it for important workplace decisions.

## 🔐 Privacy and Responsible AI

Artificial intelligence can generate inaccurate, incomplete, or misleading information. Users should exercise judgement when using AI-generated content.

### Responsible Use Guidelines

- Verify important facts and recommendations.
- Avoid submitting confidential workplace information or personal data.
- Review AI-generated emails before sending them.
- Check original sources when using research outputs.
- Do not treat AI suggestions as a replacement for professional judgement.
- Understand how the configured AI provider processes submitted information.

Data handling depends on the actual application implementation and the AI provider's policies.

## ⚙️ Architecture and Limitations

The project is intended to use a frontend-first architecture without a custom backend or database.

Depending on the implementation:

- Local browser storage may retain selected preferences or activity data.
- Genuine AI features require a compatible model or API integration.
- Website research depends on actual access to source content.
- Some websites restrict automated access.
- AI service availability, rate limits, and pricing depend on the provider.
- A frontend-only architecture cannot securely protect private API keys embedded in browser-delivered code.
- Confidential business information should not be submitted unless the integration has been appropriately assessed for privacy and security.

These limitations should be considered when demonstrating or extending the application.
